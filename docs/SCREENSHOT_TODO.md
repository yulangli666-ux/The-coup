# 截图补充清单

这份文档用于指导你补齐 GitHub README 中的项目截图。

## 一、建议至少准备 6 张图

### 1. 大厅页

- 文件名：`docs/screenshots/home.png`
- 建议内容：
  - 项目标题
  - 玩家昵称
  - 创建房间 / 加入房间 / 快速加入按钮
  - 规则入口 / 历史入口

### 2. 等待房间页

- 文件名：`docs/screenshots/waiting-room.png`
- 建议内容：
  - 4 位房间码
  - 玩家列表
  - 房主设置回合时长
  - 添加机器人按钮

### 3. 对局主界面

- 文件名：`docs/screenshots/gameplay-main.png`
- 建议内容：
  - 左右玩家布局
  - 中央日志区
  - 底部手牌与操作区
  - 回合提示

### 4. 质疑 / 阻挡阶段

- 文件名：`docs/screenshots/challenge-phase.png`
- 建议内容：
  - 中央提示区
  - 质疑按钮
  - 阻挡按钮
  - 倒计时

### 5. 大使换牌阶段

- 文件名：`docs/screenshots/exchange-phase.png`
- 建议内容：
  - 选择手牌
  - 三选一换牌区
  - 相关提示文案

### 6. 历史战绩页

- 文件名：`docs/screenshots/history-page.png`
- 建议内容：
  - 房间记录
  - 获胜者
  - 结束时间
  - 战报摘要

## 二、补图时的注意事项

- 优先使用真机截图，而不是开发者工具截图
- 避免截入微信顶部过多系统状态栏
- 一张图里尽量只突出一个页面重点
- 注意隐藏个人隐私信息
- 如果房间列表有真人昵称，确认对方同意展示或用测试账号替代

## 三、README 中可插入的图片写法

补图完成后，你可以在 `README.md` 中加入：

```md
## 页面预览

![大厅页](./docs/screenshots/home.png)
![等待房间](./docs/screenshots/waiting-room.png)
![对局界面](./docs/screenshots/gameplay-main.png)
![历史战绩](./docs/screenshots/history-page.png)
```
